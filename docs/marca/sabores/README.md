## Regras

- A imagem fica ligada à **variante/produto** no cadastro (PC), editável por humano.
  - A interface pode **sugerir** a imagem quando o nome do produto cadastrado coincidir com o sabor da tabela, mas a escolha final continua editável.
  - Nada é gravado no banco por seed ou migração.
- **Limão:** não cadastrar produto nem preço. A imagem fica disponível para quando os proprietários cadastrarem o sabor.
- Sabor sem foto usa o ícone de reserva (R3-4).
